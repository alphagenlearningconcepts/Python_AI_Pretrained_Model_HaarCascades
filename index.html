Core AI Concepts

What is a Pre-Trained Model & Haar Cascade?

1. Pre-Trained AI Model

A pre-trained model is an AI network that has already been trained on thousands or millions of sample images beforehand.

  • It comes pre-loaded with learned knowledge and patterns.
  • Saves hours of computing time and training effort.
  • Lets developers perform object detection in just 1 line of code!
Ready-to-use AI intelligence!
2. HAAR CASCADE MODEL

A Haar Cascade is a machine learning object detection algorithm trained on thousands of positive and negative images to detect light vs. dark pixel contrast boundaries.

What does the model store for each target?

👤 Face Detection Model Stores:
  • Dark eye regions vs light upper cheek contrast rectangles.
  • Light vertical nose bridge line contrast features.
😊 Smile Detection Model Stores:
  • Curved lip boundary contrast edges and teeth exposure brightness.
  • Cheek fold and mouth corner shadow variations.
🚗 Number Plate Model Stores:
  • High-contrast rectangular frame borders and character grid edges.

📹 LIVE FEED ARCHITECTURE REAL-TIME LOOP

In live video stream detection:

  • Initialize camera capture object once at startup.
  • Continuously grab incoming video frames inside a loop.
  • Convert each individual frame to grayscale.
  • Pass each grayscale frame into `detectMultiScale()`.
  • Draw bounding boxes and display each frame in real-time.
  • Break the loop when a key (like 'q') is pressed and release camera resources!
